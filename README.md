# Hangman Game

## About the Project
Hangman is a simple text-based word-guessing game developed using Python as part of the CodeAlpha Python Programming Internship (Task 1).

The player must guess a hidden word one letter at a time. The game allows a maximum of 6 incorrect guesses.

## Features
- Randomly selects a word from a predefined list.
- Displays correctly guessed letters.
- Hides unguessed letters using underscores.
- Validates user input.
- Prevents repeated guesses.
- Displays win or loss messages.
- Allows the player to play again.

## Technologies Used
- Python
- Random module
- Loops and conditional statements
- Functions
- User input and output

## How to Run
1. Install Python on your computer.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python hangman.py
```

## How to Play
1. Run the program.
2. Guess one letter at a time.
3. Correct guesses reveal the letters in the word.
4. You can make up to 6 incorrect guesses.
5. Guess the complete word to win.
6. Choose whether to play again.
